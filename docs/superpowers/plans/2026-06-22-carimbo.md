# Carimbo (Stamp) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a collapsible stamp section to the sig-modal that appends formatted multi-line text below the signature in the combined PNG sent to the backend.

**Architecture:** Two files change. `public/style.css` gets stamp section styles. `public/sig-modal.js` gets stamp HTML in `_build()`, stamp state + event handlers in `_bind()` and `open()`, plus two new methods `_renderStampPreview()` and `_combineCanvases()`. The confirm handler is updated to call `_combineCanvases()` instead of reading the sig canvas directly. Backend unchanged.

**Tech Stack:** Vanilla JS, HTML5 Canvas 2D API, localStorage.

## Global Constraints

- Modify only `public/sig-modal.js` and `public/style.css` — no other files
- No backend changes (`sign.js`, `server.js`, `app.js`, `overlay.js`, `index.html` untouched)
- Stamp disabled or empty → behaviour identical to current (pure sig PNG)
- Canvas text colour: `#2c2a28` (matches signature pen colour)
- Sig canvas fixed: 580×200px
- CSS variables already in style.css: `--bg`, `--surface`, `--border`, `--text`, `--text-muted`, `--btn-primary-bg`
- Default stamp settings: Arial, 12px, center-aligned, no bold, no italic

### Task 3: `_renderStampPreview()` method

**Files:**
- Modify: `public/sig-modal.js` — add new method after `_updatePreview()`

**Interfaces:**
- Consumes: `this._stampItalic`, `this._stampBold`, `this._stampSize`, `this._stampFont`, `this._stampAlign` (set in Task 4)
- Produces: `_renderStampPreview()` — reads `#stamp-textarea`, draws formatted text on `#stamp-preview` canvas

Note: `this._stamp*` properties are added in Task 4. This task defines the render method; it becomes callable once state exists.

- [ ] **Step 1: Add `_renderStampPreview()` after `_updatePreview()`**

In `public/sig-modal.js`, find the end of `_updatePreview()`. After its closing `}`, add:

```js
  _renderStampPreview() {
    const textarea = document.getElementById('stamp-textarea');
    const preview  = document.getElementById('stamp-preview');
    if (!textarea || !preview) return;

    const lines  = textarea.value.split('\n');
    const size   = this._stampSize;
    const lineH  = Math.round(size * 1.4);
    const padV   = 8;

    preview.width  = 580;
    preview.height = Math.max(lineH + padV * 2, lines.length * lineH + padV * 2);

    const ctx = preview.getContext('2d');
    ctx.clearRect(0, 0, preview.width, preview.height);

    const fontParts = [];
    if (this._stampItalic) fontParts.push('italic');
    if (this._stampBold)   fontParts.push('bold');
    fontParts.push(`${size}px`);
    fontParts.push(`"${this._stampFont}"`);
    ctx.font      = fontParts.join(' ');
    ctx.fillStyle = '#2c2a28';
    ctx.textAlign = this._stampAlign;

    const x = this._stampAlign === 'left' ? 8
             : this._stampAlign === 'right' ? 572
             : 290;

    lines.forEach((line, i) => {
      ctx.fillText(line, x, padV + size + i * lineH);
    });
  }
```

    this._stampFont    = localStorage.getItem('stamp_font')    || 'Arial';
    this._stampSize    = parseInt(localStorage.getItem('stamp_size') || '12', 10);

    document.getElementById('stamp-section').style.display = this._stampEnabled ? 'block' : 'none';
    document.getElementById('stamp-textarea').value        = localStorage.getItem('stamp_text') || '';

    document.getElementById('stamp-size').value            = String(this._stampSize);

- [ ] **Step 1: Add `_combineCanvases()` after `_loadStampState()`**

```js
  _combineCanvases() {
    const sigCanvas = document.getElementById('sig-modal-canvas');

    const stampActive = this._stampEnabled &&
      (document.getElementById('stamp-textarea').value.trim().length > 0);

    if (!stampActive) return sigCanvas.toDataURL('image/png');

    const stampPreview = document.getElementById('stamp-preview');
    const gap  = 8;
    const sepH = 1;

    const out = document.createElement('canvas');
    out.width  = 580;
    out.height = sigCanvas.height + gap + sepH + gap + stampPreview.height;

    const ctx = out.getContext('2d');
    ctx.drawImage(sigCanvas, 0, 0);

    // separator line
    ctx.fillStyle = '#cccccc';
    ctx.fillRect(0, sigCanvas.height + gap, 580, sepH);

    ctx.drawImage(stampPreview, 0, sigCanvas.height + gap + sepH + gap);

    return out.toDataURL('image/png');
  }
```
